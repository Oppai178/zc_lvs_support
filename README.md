# [Z-CITY] LVS SUPPORT

**Автор:** Oppai
**Версия:** 4.1.0

Слой совместимости для Garry's Mod, который связывает **[Z-CITY]** (Homigrad) и **[LVS] - Framework** (Light Vehicle System).

Аддон не патчит файлы Z-City и не заменяет Glide. Он работает как сложный мост между двумя фреймворками, позволяя LVS-технике использовать фейк-регдоллы, систему организма, камеры, TPIK и оружие Z-City.

## ⚠️ ВАЖНО: ИЗВЕСТНЫЕ ПРОБЛЕМЫ
*   **Конфликт с Glide:** Этот мод не заменяет Glide, но может ломать Glide-машины из-за перехвата камер и регдоллов. Если у вас на сервере используется Glide, используйте этот мод с осторожностью.
*   **Нестабильность (Beta):** Это сложный слой совместимости. Возможны баги с камерой (особенно в закрытой технике) и физикой (например, ОФ-снаряды).
*   **Исходный код:** Проект открыт! Если вы умеете кодить на Lua и хотите помочь с фиксом багов, заходите на мой GitHub: [ВСТАВЬ СЮДА ССЫЛКУ НА СВОЙ РЕПОЗИТОРИЙ].

## 📋 Требования
*   Z-City (Homigrad)
*   [LVS] - Framework
*   Любой пак LVS-техники (тестировалось на Snowdrop, Helicopters и др.)

## 🔥 Ключевые фичи (v4.1.0)

### Транспорт и Физика
*   **Синхронизация регдоллов:** Полноценный перенос `hg.Fake` в LVS. Тело приваривается к сиденью/шасси.
*   **Crush Guard:** Защита от разрыва игрока при авариях из-за физических контактов самого транспорта (DMG_CRUSH).
*   **Камеры (Seat Matrix):** Умное переключение. Водитель открытой машины получает камеру Z-City, стрелок в танке — прицел LVS, пилот вертолета — вид от глаз регдолла.
*   **Дроны (FPV):** Поддержка LVS-дронов, где игрок сидит в кресле оператора. Камера берется из самого дрона.
*   **Краш-система:** Реалистичные травмы при столкновениях. Удар головой в стену на высокой скорости ломает кости, а не просто снимает HP.

### Оружие и Взрывы (HE)
*   **Z-City HE Pipeline:** Интеграция тяжелых снарядов (ОФ) в родную систему Z-City. Осколки, контузия, звуки взрывов гранат и частицы.
*   **Пробитие стекол:** Пули пролетают сквозь стекла и открытые двери, нанося урон сидящим внутри.

### Взаимодействие и Механики
*   **Force Seat (ArmA-style):** Радиальное меню позволяет силой посадить бессознательного игрока в машину или вытащить его из нее.
*   **Грузовой отсек:** Возможность лежать в кузове (с закрытыми дверями вас не выкинет).
*   **Черный ящик:** Встроенная система логирования (`zc_lvs_dump`) для дебага серверных багов.

## 🎮 Управление
*   **1–0** — Оружие техники
*   **Alt + 1–0** — Смена сиденья
*   **E** — Выход из машины
*   **R** — Перезарядка / Запуск двигателя (в зависимости от наличия оружия в руках)

## ⚙️ Консольные переменные (ConVars)
| CVar | По умолчанию | Описание |
|---|---|---|
| `zc_lvs_enabled` | 1 | Включить/выключить весь слой. |
| `zc_lvs_fake` | 1 | Использовать регдолл (фейк) в салоне. |
| `zc_lvs_air_fake` | 1 | Использовать фейк в вертолетах/самолетах. |
| `zc_lvs_air_lvcam` | 0 | Использовать нативную камеру LVS для авиации. |
| `zc_lvs_forceseat` | 0 | Разрешить радиальное меню для посадки/высадки. |
| `zc_lvs_he_fx` | 1 | Включить Z-City эффекты и осколки для снарядов LVS. |
| `zc_lvs_crash_damage` | 1 | Перенос урона от аварий в организм. |
| `zc_lvs_debug` | 0 | Вывод отладочной информации в консоль. |

## 🛠 Структура проекта (Для разработчиков)
*   `lua/autorun/sh_zc_lvs_support.lua` — Точка входа, версии, инициализация.
*   `lua/zc_lvs_support/sh_core.lua` — Матрица сидений, проверки типов техники, ConVars.
*   `lua/zc_lvs_support/sv_seats.lua` — Логика фейков, сварка, сброс координат.
*   `lua/zc_lvs_support/sv_organism.lua` — Конвертация урона LVS в урон организма. Crush Guard.
*   `lua/zc_lvs_support/sv_he.lua` — Родные взрывы, осколки и контузия.
*   `lua/zc_lvs_support/sv_forceseat.lua` — Серверная логика принудительной посадки.
*   `lua/zc_lvs_support/cl_camera.lua` — Перехват камер, плавное следование.
*   `lua/zc_lvs_support/cl_tpik.lua` — Синхронизация рук (TPIK) с рулем.
*   `lua/zc_lvs_support/sv_cargo.lua` — Логика кузова и перевозки тел.
