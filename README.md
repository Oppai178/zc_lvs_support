# [Z-CITY] LVS SUPPORT

Автор: **Oppai**

Прослойка совместимости между **LVS** (техника) и **Z-City / Homigrad**
(организм, фейк-регдоллы, TPIK). Посаженный в технику игрок становится
настоящим телом: по нему попадает через стекло, при аварии он получает
травмы, в отрубе его можно вытащить. Референс поведения — **ArmA Reforger**.

Файлы Z-City и LVS **не патчатся** — всё через хуки и обёртки.
Glide не затрагивается.

## Требования

- Z-City (Homigrad)
- `[LVS] - Framework`
- любой LVS-пак техники

Мод рассчитан на **весь фреймворк LVS**, а не на конкретные паки:
классификация идёт по типу, цепочке базовых классов и характерным
методам, без хардкодов под отдельные машины.

## Установка

Папку `zc_lvs_support` — в `garrysmod/addons/`.
После захода на карту в консоли:

```
[Z-CITY LVS SUPPORT] loaded v4.2.0 by Oppai
```

Если вместо этого `waiting for: LVS` или `hg` — мод ждёт загрузку
соответствующей системы и повторит попытку сам.

## Управление

| Клавиши | Действие |
|---|---|
| **1–0** | оружие техники |
| **Alt + 1–0** | смена места |
| **E** | выход |
| **ПКМ** | прицел LVS на месте стрелка |
| **Ctrl** | наклон Z-City (третьего лица в игре нет) |

Alt не выходит из машины (у Z-City это «идти шагом»), Shift/Alt в салоне
не карабкаются руками фейка.

## Что работает

**Наземная техника**
- фейк-регдолл на местах, камера Z-City от глаз тела
- руки на руль (TPIK), если у модели есть кость `steering` / `steeringwheel`
- урон по организму: ДТП, пробитие стёкол/дверей, калибр против брони,
  утечка топлива и пожар, взрыв машины
- отключка за рулём глушит машину, но не выкидывает из неё
- тело в отрубе падает с настоящим весом, его можно вытащить за руки

**Закрытая броня (танки, БТР)**
- места, которые пак прячет (водитель за бронёй) — родной вид LVS
- десантные места с трапом и стрелок в люке — камера Z-City, тело видно
- броня режет урон от HE и пуль

**Авиация**
- фейк есть на всех местах, камера по умолчанию от глаз фейка
- мышь пилота кормит штурвал LVS, пассажир крутит головой по-Z-City
- `zc_lvs_air_lvcam 1` возвращает родную камеру LVS, если пак требует

**HE-снаряды**
- поверх урона LVS проигрывается взрывной конвейер Z-City: осколки
  «Metal Debris», звук детонации, частицы, тряска, след копоти

## Консольные переменные

| CVar | По умолч. | Смысл |
|---|---|---|
| `zc_lvs_enabled` | 1 | весь слой |
| `zc_lvs_fake` | 1 | фейк-регдоллы в технике |
| `zc_lvs_air_fake` | 1 | фейк в авиации |
| `zc_lvs_air_lvcam` | 0 | родная камера LVS в авиации (0 = глаза ZC) |
| `zc_lvs_crash_damage` | 1 | ДТП → организм |
| `zc_lvs_explode_damage` | 1 | взрыв машины → организм |
| `zc_lvs_crash_eject` | 0 | выброс при ДТП (устаревшее, выключено) |
| `zc_lvs_pen` | 1 | пули через стекло/двери в салон |
| `zc_lvs_shrapnel` | 1 | осколки при взрыве |
| `zc_lvs_fuel_leak` | 1 | утечка топлива и возгорание |
| `zc_lvs_air_fall` | 0 | выпадение из вертолёта в отрубе |
| `zc_lvs_he_fx` | 1 | эффекты HE через Z-City |
| `zc_lvs_debug` | 0 | диагностика в консоль |
| `zc_lvs_forceseat` | 0 | принудительная посадка (не проверено) |

## Диагностика

```
zc_lvs_status              — загрузился ли мод, видит ли LVS и hg
zc_lvs_debug_seats [ник]   — снимок места: pod/chassis, режим камеры,
                             роль, фейк, позиция камеры
zc_lvs_dump                — записать лог сессии
zc_lvs_tail 40             — последние 40 строк лога
zc_lvs_clear               — очистить буфер лога
```

Лог сессии пишется в `garrysmod/data/zc_lvs/`: нумерованные
`session_N.txt` при выходе, плюс `live_mirror.txt` каждые 30 с и
снимки на смерть/крупный урон.

## Если что-то не так

1. `zc_lvs_status` — мод должен быть `loaded`.
2. LVS Framework включён?
3. Не добавляй LVS-классы в **Vehicle ragdoll blacklist** Z-City —
   это отключит фейк.
4. `zc_lvs_debug_seats` на проблемном месте — снимок покажет, в какую
   ветку классификации попала техника.

## Структура кода

```
lua/autorun/sh_zc_lvs_support.lua   загрузчик, диагностика мест
lua/autorun/server/zc_lvs_dump.lua  логгер сессии
lua/zc_lvs_support/
  sh_core.lua       ядро: классификация, матрица мест, режим камеры
  sh_binds.lua      разведение клавиш (shared)
  sv_seats.lua      фейк-регдоллы: посадка, езда, выход, отключка
  sv_organism.lua   урон: ДТП, HE, пробитие, броня, топливо, пожар
  sv_he.lua         HE-снаряды через взрывной конвейер Z-City
  sv_interior.lua   удержание тел/пропов в кузове (выключено)
  sv_cargo.lua      посадка в кузов (выключено)
  sv_forceseat.lua  принудительная посадка (выключено)
  cl_camera.lua     камера и мышь всех режимов
  cl_tpik.lua       руки (TPIK) и фильтр взгляда
  cl_binds.lua      клиентские бинды
  cl_cargo.lua      HUD кузова
  cl_forceseat.lua  меню принудительной посадки
tools/check_lua.py  синтакс-чекер (реальный Lua через lupa)
```

Проверка синтаксиса: `pip install lupa` → `python tools/check_lua.py`.
